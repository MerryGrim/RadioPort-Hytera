# RadioPort · Hytera

Канал Android-выпусков RadioPort · Hytera, пакет `app.radioport.hytera`, Android 6.0 и новее.

[Последний выпуск и APK](https://github.com/MerryGrim/RadioPort-Hytera/releases/latest)

Приложение открывает кодплаги на телефоне и читает поддержанные радиостанции через Android USB Host / OTG. Основная работа с локальными файлами и рацией доступна без интернета. Сеть используется для проверки и загрузки обновлений из этого канала; установку подтверждает системный установщик Android.

Приложение показывает распознанные каналы, зоны, контакты, списки, имя станции, DMR ID, общие параметры, назначения кнопок, быстрые тексты и действия одним нажатием. Есть диагностический обзор структуры. Семантическое декодирование CPS пока частичное: исходные байты и неизвестные поля сохраняются отдельно, а количество секций не означает поддержку всех настроек.

Перенос исходного подготовленного на ПК файла в рацию остаётся экспериментальным. Физическая запись HP785 этой версией не подтверждена. Доступность функций устройства и лицензий не определяется по одному названию модели или данным файла. Уточнения и фактическое покрытие проверок приводятся в описании каждого выпуска.

## Обновления

Начиная с 0.6.2 приложение проверяет канал при открытии не чаще раза в сутки и автоматически загружает новую версию. Сначала установите APK последнего выпуска обычным способом; далее используйте встроенный раздел «Обновления». Кнопка «Проверить обновления» работает и при отключённом автоматическом режиме. Android запрашивает подтверждение установки.

Приложение получает метаданные последнего выпуска по адресу:

`https://github.com/MerryGrim/RadioPort-Hytera/releases/latest/download/update.json`

Метаданные связывают номер версии, APK, его размер и SHA-256. Перед передачей установщику приложение проверяет пакет, версию и сертификат подписи. Действующий сертификат SHA-256:

`AA81C8B56B9DFA24ACCB08AE185FFBED8DD61A79F4EE1BC0F071A22D7B5F52D4`

Для обновления сохраняется существующая подпись. APK и `update.json` публикуются как assets выпусков; ключ подписи хранится локально у владельца.
